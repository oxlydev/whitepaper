## GitBook

Each language folder is a self-contained GitBook space with its own `.gitbook.yaml`, `README.md`, and `SUMMARY.md`.
To publish, create one GitBook space per language, enable **Git Sync** with this repository, and set the
**project directory** to `en` or `id`.
